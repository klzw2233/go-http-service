# 添加中间件

> 项目：`go-http-service`  
> 主题：如何在 Gin 项目中添加日志、恢复、CORS 中间件

---

## 一、什么是中间件

中间件（Middleware）是位于 HTTP 请求到达 Handler **之前** 和离开 Handler **之后** 执行的一段代码。

```text
请求 → 中间件 A → 中间件 B → Handler → 中间件 B 后续 → 中间件 A 后续 → 响应
```

每个中间件可以做一件事：

- 记录请求日志
- 捕获 panic 防止服务崩溃
- 允许跨域请求
- 验证用户身份
- 统计请求耗时

---

## 二、Gin 中间件基础

Gin 使用 `gin.HandlerFunc` 作为中间件类型：

```go
func MyMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        // 请求前执行
        start := time.Now()

        // 继续执行后续 Handler
        c.Next()

        // 请求后执行
        duration := time.Since(start)
        log.Printf("%s %s took %v", c.Request.Method, c.Request.URL.Path, duration)
    }
}
```

注册中间件：

```go
r := gin.Default()
r.Use(MyMiddleware())  // 全局中间件
```

## 三、日志中间件

### 3.1 为什么需要日志中间件

`gin.Default()` 默认已经自带了日志输出，但格式固定：

```
[GIN] 2026/08/21 - 11:47:39 | 200 |  512.5µs |       192.0.2.1 | GET      "/api/health"
```

生产环境通常需要更结构化的日志，比如 JSON 格式：

```json
{
  "level": "info",
  "method": "GET",
  "path": "/api/health",
  "status": 200,
  "duration": 512500,
  "client_ip": "192.0.2.1"
}
```

### 3.2 使用 zap 日志库

常用高性能日志库：`go.uber.org/zap`

安装：

```bash
go get go.uber.org/zap
```

自定义中间件：

```go
func LoggerMiddleware(logger *zap.Logger) gin.HandlerFunc {
    return func(c *gin.Context) {
        start := time.Now()
        path := c.Request.URL.Path

        c.Next()

        logger.Info("request",
            zap.String("method", c.Request.Method),
            zap.String("path", path),
            zap.Int("status", c.Writer.Status()),
            zap.Duration("duration", time.Since(start)),
            zap.String("client_ip", c.ClientIP()),
        )
    }
}
```

## 四、Recovery 中间件

### 4.1 为什么需要 Recovery

如果 Handler 里出现 panic，整个程序会崩溃。Recovery 中间件可以捕获 panic 并返回 500 错误，而不是让服务挂掉。

`gin.Default()` 默认已经包含 Recovery 中间件。

### 4.2 自定义 Recovery

```go
func RecoveryMiddleware() gin.HandlerFunc {
    return func(c *gin.Context) {
        defer func() {
            if err := recover(); err != nil {
                log.Printf("panic recovered: %v", err)
                c.AbortWithStatusJSON(http.StatusInternalServerError, gin.H{
                    "error": "internal server error",
                })
            }
        }()

        c.Next()
    }
}
```

## 五、CORS 中间件

### 5.1 什么是 CORS

CORS（Cross-Origin Resource Sharing）是浏览器的安全策略。当前端页面和 Go 服务端不在同一个域名或端口时，浏览器会阻止前端直接访问后端。

### 5.2 使用 gin-contrib/cors

最方便的 CORS 中间件：

```bash
go get github.com/gin-contrib/cors
```

配置：

```go
import "github.com/gin-contrib/cors"

func main() {
    r := gin.Default()

    r.Use(cors.New(cors.Config{
        AllowOrigins:     []string{"http://localhost:3000"},
        AllowMethods:     []string{"GET", "POST", "PUT", "DELETE", "OPTIONS"},
        AllowHeaders:     []string{"Origin", "Content-Type", "Authorization"},
        AllowCredentials: true,
        MaxAge:           12 * time.Hour,
    }))

    r.Run(":8080")
}
```

### 5.3 开发环境配置

开发时可以放宽限制，允许所有来源：

```go
r.Use(cors.Default())
```

但生产环境不要这样做。

## 六、应用到当前项目

### 6.1 中间件注册顺序

中间件顺序非常重要。推荐顺序：

```go
r := gin.Default()

r.Use(RecoveryMiddleware())    // 最先注册，捕获所有 panic
r.Use(LoggerMiddleware(logger)) // 记录所有请求
r.Use(CORSMiddleware())        // 处理跨域

// 路由注册
r.GET("/api/health", healthHandler)
```

### 6.2 中间件 vs Handler

| 组件 | 职责 |
|------|------|
| 中间件 | 处理通用横切关注点（日志、安全、恢复） |
| Handler | 处理具体业务逻辑 |

## 七、其他常见中间件

| 中间件 | 作用 |
|--------|------|
| 请求限流 | 防止恶意请求或 DDoS |
| JWT 鉴权 | 验证用户身份 |
| 请求 ID | 给每个请求加唯一 ID，方便追踪日志 |
| 压缩 | gzip 压缩响应体 |
| 静态文件服务 | 提供前端静态资源 |

---

## 八、什么时候引入中间件

建议在以下时机引入：

- 项目开始对外提供服务时
- 前端需要访问后端时（CORS）
- 需要统一日志格式时
- 添加用户认证系统时（JWT 鉴权中间件）

对于当前项目，引入中间件的优先顺序：

1. **CORS**：当前端 Vue 项目需要访问后端时最先需要
2. **结构化日志**：项目工程化的标志
3. **JWT 鉴权**：用户系统完成后必须加
4. **请求限流/压缩**：性能优化阶段

## 九、开发配置建议

环境变量控制中间件行为：

```bash
LOG_LEVEL=debug
CORS_ALLOW_ORIGINS=http://localhost:5173,http://localhost:3000
JWT_SECRET=your-secret-key
```

---

## 十、中间件是项目工程化的起点

添加中间件意味着项目开始从「可用」走向「可维护」。它是一个分水岭：

- 出现错误有日志可查
-  panic 不会导致崩溃
- 前端可以正常访问后端
- 接口可以被统一管控

完成中间件后，项目就具备了生产环境的基本条件。

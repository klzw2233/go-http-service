# 实现用户注册/登录接口

> 项目：`go-http-service`  
> 主题：如何在 Go 项目中实现用户注册和登录接口

---

## 一、为什么先做用户系统

用户系统是几乎所有后端项目的核心基础：

- 博客系统：需要知道文章是谁写的
- 文件管理：需要区分文件归属
- AI 服务：需要记录用户调用配额
- 下载工具：需要记录用户任务

掌握了用户注册、登录、JWT 认证这套流程，后面做其他功能都会重复用到这套模式。

---

## 二、用户系统的核心流程

用户系统主要由三个接口组成：

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/auth/register` | POST | 用户注册 |
| `/api/auth/login` | POST | 用户登录 |
| `/api/auth/me` | GET | 获取当前用户信息（需登录） |

```text
注册：
客户端发送用户名/邮箱/密码
          ↓
      服务端校验
          ↓
       密码哈希
          ↓
    写入数据库
          ↓
    返回成功

登录：
客户端发送用户名/密码
          ↓
      服务端校验
          ↓
    查询数据库
          ↓
    比对密码哈希
          ↓
    生成 JWT Token
          ↓
    返回 Token
```

## 三、密码哈希

### 为什么不能明文存储密码

数据库一旦泄露，所有用户密码都会暴露。实践中**绝对不要**明文存储密码。

### 常用哈希算法

| 算法 | 说明 | 推荐 |
|------|------|------|
| bcrypt | 最常用，Go 标准库支持，自适应成本 | ✅ 推荐 |
| scrypt | 内存困难型，适合加密货币 | 可选 |
| Argon2 | 现代密码哈希冠军 | 可选 |

Go 中 bcrypt 的使用：

```go
import "golang.org/x/crypto/bcrypt"

// 生成哈希
hash, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)

// 验证密码
err := bcrypt.CompareHashAndPassword([]byte(hash), []byte(password))
```

## 四、JWT 认证

### 4.1 什么是 JWT

JWT（JSON Web Token）是一种紧凑、自包含的认证令牌。用户登录后，服务端签发一个 JWT，客户端后续请求都带上这个令牌。

### 4.2 JWT 的结构

```
header.payload.signature
```

| 部分 | 内容 |
|------|------|
| Header | 签名算法和 Token 类型 |
| Payload | 用户 ID、用户名、过期时间等 |
| Signature | 用密钥签名，防止篡改 |

### 4.3 Go 实现

Go 常用的 JWT 库：

```bash
go get github.com/golang-jwt/jwt/v5
```

生成 Token：

```go
import "github.com/golang-jwt/jwt/v5"

func GenerateToken(userID int64, secret string) (string, error) {
    token := jwt.NewWithClaims(jwt.SigningMethodHS256, jwt.MapClaims{
        "user_id": userID,
        "exp":     time.Now().Add(time.Hour * 24).Unix(),
    })

    return token.SignedString([]byte(secret))
}
```

验证 Token：

```go
func ParseToken(tokenString string, secret string) (int64, error) {
    token, err := jwt.Parse(tokenString, func(token *jwt.Token) (interface{}, error) {
        return []byte(secret), nil
    })

    if claims, ok := token.Claims.(jwt.MapClaims); ok && token.Valid {
        userID := int64(claims["user_id"].(float64))
        return userID, nil
    }
    return 0, err
}
```

## 五、接口设计

### 5.1 注册接口

```http
POST /api/auth/register
Content-Type: application/json

{
  "username": "jimmy",
  "email": "jimmy@example.com",
  "password": "123456"
}
```

响应：

```json
{
  "id": 1,
  "username": "jimmy",
  "email": "jimmy@example.com",
  "created_at": "2026-08-21T10:00:00Z"
}
```

### 5.2 登录接口

```http
POST /api/auth/login
Content-Type: application/json

{
  "username": "jimmy",
  "password": "123456"
}
```

响应：

```json
{
  "token": "eyJhbGciOiJIUzI1NiIs..."
}
```

### 5.3 获取当前用户

```http
GET /api/auth/me
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
```

响应：

```json
{
  "id": 1,
  "username": "jimmy",
  "email": "jimmy@example.com"
}
```

## 六、应用到当前项目

### 6.1 新增文件

```
internal/
├── handler/
│   ├── auth_handler.go        # 注册/登录接口
│   └── router.go              # 更新路由
├── service/
│   └── user_service.go        # 用户业务逻辑
├── repository/
│   └── user_repository.go     # 用户数据访问
└── model/
    └── user.go                # 用户结构体
```

### 6.2 用户模型

```go
package model

type User struct {
    ID           int64  `json:"id"`
    Username     string `json:"username"`
    Email        string `json:"email"`
    PasswordHash string `json:"-"`  // 不序列化到 JSON
    CreatedAt    string `json:"created_at"`
}
```

### 6.3 Repository 层

```go
func (r *UserRepository) FindByUsername(username string) (*model.User, error) {
    query := `
        SELECT id, username, email, password_hash, created_at
        FROM users
        WHERE username = $1
    `
    row := r.db.QueryRow(query, username)
    user := &model.User{}
    err := row.Scan(&user.ID, &user.Username, &user.Email, &user.PasswordHash, &user.CreatedAt)
    return user, err
}
```

### 6.4 Service 层

```go
type UserService struct {
    repo *repository.UserRepository
}

func (s *UserService) Register(username, email, password string) (*model.User, error) {
    hash, err := bcrypt.GenerateFromPassword([]byte(password), bcrypt.DefaultCost)
    if err != nil {
        return nil, err
    }

    user := &model.User{
        Username:     username,
        Email:        email,
        PasswordHash: string(hash),
    }

    if err := s.repo.Create(user); err != nil {
        return nil, err
    }

    return user, nil
}
```

## 七、鉴权中间件

登录后的接口需要保护，使用 Gin 中间件验证 JWT：

```go
func AuthMiddleware(secret string) gin.HandlerFunc {
    return func(c *gin.Context) {
        authHeader := c.GetHeader("Authorization")
        tokenString := strings.TrimPrefix(authHeader, "Bearer ")

        userID, err := ParseToken(tokenString, secret)
        if err != nil {
            c.AbortWithStatusJSON(http.StatusUnauthorized, gin.H{"error": "unauthorized"})
            return
        }

        c.Set("user_id", userID)
        c.Next()
    }
}
```

使用中间件保护接口：

```go
auth := r.Group("/api")
auth.Use(AuthMiddleware(secret))
auth.GET("/auth/me", meHandler)
```

## 八、安全注意事项

| 项目 | 说明 |
|------|------|
| 密码哈希 | 永远哈希存储，不要明文 |
| JWT 密钥 | 放到环境变量，不要硬编码 |
| Token 过期 | 设置合理的过期时间，如 24 小时 |
| 用户名唯一 | 数据库加唯一索引 |
| 密码强度 | 前端后端都要校验最小长度 |
| HTTPS | 生产环境必须用 HTTPS 传输 |

## 九、测试要点

用户系统测试需要特别注意：

- 注册成功
- 用户名重复返回 409
- 登录成功返回 JWT
- 登录密码错误返回 401
- 没有 Authorization 访问 `/api/auth/me` 返回 401
- Token 错误返回 401
- Token 过期返回 401

# A Published Post is edited in place; there is no revision history

Changing the Title or Body of a Published Post does not Unpublish it. Readers see the new writing on the next open. The Slug still does not change. There is one Body, not a published copy and a working copy.

Forcing Unpublish to edit would have 404'd a public URL for a typo. Storing revisions would have been a second product. The cost is that a half-finished save is publicly readable. The Author is one person and is expected to save finished text.
